# Reproducible Vectors

`demo-round.json` and `demo-round.pubkey` are generated by `cigp generate-demo-round test-vectors`. They are deterministic fixtures for the reference profile and contain no production secret. The included `server_seed` is intentionally a public demo value.

```text
cargo run -p cigp -- generate-demo-round test-vectors
cargo run -p cigp -- verify test-vectors/demo-round.json
```
